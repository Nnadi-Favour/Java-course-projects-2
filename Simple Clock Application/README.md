# Simple Clock Application

## Overview
A Java console application that displays the current date and time using multiple threads.

## Features
- Updates the clock continuously.
- Displays the time in HH:mm:ss format.
- Displays the date in dd-MM-yyyy format.
- Uses separate threads for updating and displaying the clock.

## Concepts
Java, multithreading, thread priorities, shared data and LocalDateTime.

## Run
**Compile:** `javac Unit3.java Clock.java TimeUpdater.java TimeDisplay.java`

**Run:** `java Unit3`

Note: Thread priorities are scheduling hints and do not guarantee execution order.
