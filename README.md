# Java Course Projects

A collection of six Java projects developed to demonstrate programming concepts, object-oriented design, data structures, generics, multithreading, networking and desktop application development.

## Projects

### 1. Java Text Analysis Tool
Analyzes text to calculate character counts, word counts, character frequency and unique words.

### 2. E-commerce System
A console-based shopping application with product inventory, shopping cart management and order processing.

### 3. Simple Clock Application
Demonstrates Java multithreading through a continuously updating digital clock.

### 4. Generic Library Catalog
Uses Java generics to manage books and DVDs in a searchable library catalog.

### 5. Online Chat Application
A client-server chat application that supports communication between multiple clients.

### 6. Weather App
A Java Swing desktop application that displays current weather and a five-day forecast using Open-Meteo.

## Technologies and Concepts
- Java
- Object-oriented programming
- Java Collections and Generics
- Exception handling
- Multithreading
- Socket programming
- Java Swing
- Maven
- HTTP and JSON

## Getting Started

Each project is contained in its own folder and has a README with its features and instructions for compiling and running it.

Some projects require additional tools or an internet connection.

## Purpose

These projects demonstrate practical Java programming skills and the application of concepts learned through coursework.
