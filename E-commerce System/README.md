# E-commerce System

## Overview
A Java console application demonstrating a basic online shopping workflow.

## Features
- View sample products and available stock.
- Add and remove products from a shopping cart.
- Calculate cart totals and product subtotals.
- Confirm or cancel orders.
- Generate order summaries and update inventory.

## Concepts
Java, object-oriented programming, ArrayList, encapsulation and exception handling.

## Run
```bash
javac -d out Unit2.java src/com/ecommerce/Customer.java src/com/ecommerce/Product.java src/com/ecommerce/orders/Order.java
java -cp out Unit2


```

This educational application uses sample in-memory data. It does not include a database or online payment integration.
