# Java Text Analysis Tool

## Overview

The Java Text Analysis Tool is a console-based application that analyses text entered by the user and provides useful statistical information about its content.

The application processes a paragraph, calculates character and word counts, identifies the most frequently occurring character, and allows users to search for specific characters and words.

It also determines the number of unique words in the submitted text.

## Features

- Accepts paragraph or lengthy text input.
- Validates empty text submissions.
- Calculates the total number of characters.
- Counts the total number of words.
- Identifies the most frequently occurring character.
- Calculates the frequency of a user-selected character.
- Calculates the frequency of a user-selected word.
- Counts the number of unique words.
- Handles text searches without case sensitivity.

## How to Run

1. Open the project folder in a Java development environment.
2. Open the terminal inside the project folder.
3. Compile the source file:

   ```bash
   javac Unit1.java
   ```

4. Run the application:

   ```bash
   java Unit1
   ```

5. Enter a paragraph when prompted and follow the instructions.
