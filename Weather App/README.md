# Weather App

## Overview
A Java desktop application that retrieves and displays current weather information and a five-day forecast.

## Features
- Search for weather by city.
- Display current temperature and weather conditions.
- Show humidity and wind speed.
- View a five-day weather forecast.
- Switch between Celsius and Fahrenheit.
- Switch between km/h and mph.
- Keep a history of recent searches.

## Concepts
Java, Swing, HTTP requests, JSON, SwingWorker and Maven.

## Requirements
- Java 17 or later.
- Maven.
- Internet connection.
- A graphical desktop environment.

## Run
**Compile:** `mvn clean compile`

**Run:** `mvn exec:java`

Weather information is retrieved from the Open-Meteo service. An internet connection is required.
