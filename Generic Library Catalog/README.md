# Generic Library Catalog

## Overview
A Java console application that manages books and DVDs using generic classes.

## Features
- Add books and DVDs to the catalog.
- Remove items using their IDs.
- Search for items.
- Display all catalog items.
- Store different item types using a generic catalog.

## Concepts
Java generics, inheritance, encapsulation, ArrayList and object-oriented programming.

## Run
**Compile:** `javac Unit6.java LibraryItem.java Catalog.java Book.java DVD.java`

**Run:** `java Unit6`

Note: Catalog data is stored in memory and is not saved after the application closes.
